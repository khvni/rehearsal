# No AI tics

Write like a person explaining something to a colleague. Cut these ten moves — they are the fingerprint of AI prose. Each entry shows the tic and an example.

## The tics

| Tic | What it looks like | What to do instead |
| --- | --- | --- |
| Negation-first reveal | "It is not a wrong answer. It is a non-answer." | Say what it is. Don't clear away a wrong version first. |
| Significance designation | "It is the leg that answers the actual question." | Answer the question. Don't announce that something answers it. |
| Abstraction agency | "Median hides it. The table shows it." | Inanimate things don't act. Say who hides or shows, or restructure so nobody needs to. |
| Deferred noun | "Five of those six rows are one cluster. The sixth is not." | Name the thing on first mention. Suspense belongs in fiction. |
| Coy or thesis-shaped header | "What 'exhausted' means" / "The one gap that does clear the bar" | Headers name the topic plainly: "Exhausted", "Gaps that clear the bar". No teasers, no verdicts. |
| Aphoristic closer | "It is the kind of number that looks like evidence and is not." | End on the fact, not on an aphorism about the fact. |
| Straw-man knockdown | "'It thinks twice as long' is the obvious reading, and it is wrong." | Don't erect a misreading to knock it down. State the right reading. |
| Fragment cadence | "Six legs. One GPU, one server build, one sampler, one question set." | Vary rhythm. A string of clipped fragments reads as performed intensity, not information. |
| Dressed metaphor | "That is information loss wearing the costume of a style fix." | If the metaphor does more work than the claim, drop the metaphor. |
| Label-first framing | "The fucking left column of this table." | Don't narrate where to look with emotional emphasis. Point plainly: "the left column". |

## How to use it

1. Draft normally.
2. Before saving or sending, reread and ask of every sentence: which tic is this closest to?
3. Rewrite the sentence to say the thing directly. Most fixes are deletions.
4. Keep facts and structure. The target is plainer prose, not different content.

## Tests for plainness

- A sentence survives being read aloud without drama.
- No sentence exists only to set up or underline another sentence.
- Numbers, names, and objects appear at the point a reader needs them, not after.
